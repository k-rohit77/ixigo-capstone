How it works: prompt, logic and guardrails
  1. AI understands, it does not invent. The model only turns the traveller's words into priority weights, hard limits (budget, modes to avoid, arrival deadline) and a short summary. It never sees prices it could change and never names a train.
  2. Ranking is transparent code. Score = Σ weight × factor, over certainty (own berth + 0.5 × RAC), timing fit, total price for all travellers, journey time, station convenience, seats-together and comfort. Options breaking a hard limit are removed and listed.
  3. Backup rule. The backup is always the best confirmed option other than the top pick.
  4. Honest language. Chances are shown as own berth / RAC / stays WL. The words "guaranteed" and "sure" are blocked from the answer text.
  5. Works without AI. If AI is unavailable, a keyword parser (English + Hinglish) sets the weights so the page still answers.
