Trip Resolver: say it in your own words

  • Claude turns “3 of us, mother is 65, reach by Sunday, ₹5,000” into weights and limits
  • Transparent code ranks real options; AI never invents trains or prices
  • Same honest odds; “guaranteed” is blocked
  • Works in Hinglish; keyword fallback if AI is down
As an extension, I vibe-coded a Trip Resolver. The user types their situation in their own words, even in Hinglish. Claude turns it into priorities and hard limits, like budget or no buses. Then transparent code ranks the real options, so the AI never invents a train or a price. The answer uses the same honest odds and blocks words like guaranteed. In ixigo this would sit inside TARA.
